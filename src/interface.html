GET/api/v1/signal/current
Returns current 15-min BTC/USDT signal. INPUT — 96-candle sliding window → OUTPUT direction + confidence + position size
// Response { "timestamp": "2025-02-01T14:30:00Z", "pair": "BTCUSDT", "input_window": "candles_1_to_96", // INPUT "predicted_candle": 97, // OUTPUT — which candle is predicted "direction": "LONG", // OUTPUT — LONG / SHORT / SKIP "confidence": 0.80, "models_agree": 4, "models_total": 5, "velocity_multiplier": 1.4, "recommended_position": 1300, "experiment_version": "V4" }
GET/api/v1/performance
Equity, win rate, drawdown, Sharpe ratio for the active experiment version
Python Quick Start
import requests r = requests.get( 'https://signalbot-v9.com/api/v1/signal/current', headers={'Authorization': 'Bearer sk-xxxxx'} ) signal = r.json() print(signal['direction']) # OUTPUT: 'LONG' or 'SHORT' print(signal['predicted_candle']) # OUTPUT: 97 (next candle index) print(signal['confidence']) # OUTPUT: 0.80
